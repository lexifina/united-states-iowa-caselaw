# State v. Hanysh

## Majority (PER CURIAM.)

PER CURIAM.
While this appeal was pending, we decided State v. Gorham, 206 N.W.2d 908 (Iowa). That decision governs this case. We therefore reverse the judgment with directions to dismiss the county attorney’s information.
Reversed.
